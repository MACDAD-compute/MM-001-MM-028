MM-001–MM-028

**Encounters with Roadside Giants, 2021–2026**

28 encounters · 68 photographs · GPS-derived locations · chronological sequence

---

MM-001–MM-028 is an ongoing photographic and geographic record of encounters with large-scale roadside fiberglass figures in the United States.

The archive begins with photographs made incidentally during travel and treats those photographs as records of encounter rather than as a comprehensive survey.

Each encounter is assigned an accession number in chronological order.

A repeated encounter with the same figure receives a new number.

Locations are derived primarily from photographic GPS metadata. Figure identifications and classifications are researched separately from the original photographic record.

The line connecting encounters in the corresponding geographic work represents chronological sequence, not a literal travel route.

## Classification

The archive uses “Roadside Giant” as an umbrella category.

Figures include original and modified Muffler Men, Uniroyal Gals, Bunyan / Lumberjack figures, Cowboys, Indian-type figures, Halfwit / Snerd figures, contemporary derivatives, multi-figure collections, and other related monumental roadside figures.

Classification describes the archive; it does not establish an authoritative taxonomy of roadside fiberglass figures.

## Method

photograph → EXIF metadata → encounter → identification → classification → geographic record
